# Ideas Bucket

This repository is a home for app ideas, experiments, and small projects organized as individual folders.

## Purpose

Use this repo to collect and organize:

- app ideas
- prototype projects
- experiments and proofs of concept
- concept folders that may later become standalone projects

Each idea or app lives in its own folder so it stays easy to browse, test, and expand.

## Folder structure

```text
ideas-bucket/
├── README.md
├── app-name/
│   ├── README.md
│   ├── src/
│   └── ...
├── idea-name/
│   ├── README.md
│   └── ...
└── ...
```

## Contributing

When adding a new app or idea:

1. Create a new folder with a clear, descriptive name.
2. Add a short README inside that folder describing the concept and purpose.
3. Keep related files inside the same folder.
4. Keep the root README updated as the repository grows.

## Notes

This repository is meant to be a flexible bucket for ideas and early-stage work. Some folders may later evolve into fully independent projects, while others may remain as concepts and experiments.
