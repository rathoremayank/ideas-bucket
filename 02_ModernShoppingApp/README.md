# Modern Shopping App

A clean, search-first shopping prototype. Shoppers describe what they need, answer two quick preference questions, and see every matching item on a results page. Hovering or focusing a result previews its rating and customer feedback; selecting it opens a detailed product page. Built with plain HTML, CSS, and JavaScript so it can be opened directly in a browser without a build step.

## Project structure

- `0_requirements/` — product requirements and user stories
- `1_src/` — storefront source files

## Run locally

Open `1_src/index.html` in a modern browser. The guided search, full results page, product details, and basic cart subtotal work in this starter. The catalog includes 104 items: four featured products and 100 additional products. Ratings and feedback are sample content; checkout and accounts are not implemented yet.

## Current starter features

- Search-first flow with two preference questions
- 104 searchable products across home, kitchen, workspace, travel, outdoors, wellness, accessories, stationery, lighting, and storage
- Dedicated results page with all matching items
- Hover/focus rating and customer-feedback previews
- Individual product detail pages with sample reviews
- Responsive layout and clear no-match state
- Add-to-cart count and subtotal maintained between pages

See [app requirements](0_requirements/app-requirements.md) and [user stories](0_requirements/user-stories.md) for the product scope.
